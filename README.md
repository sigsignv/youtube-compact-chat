# YouTube CompactChat

A browser extension that automatically compacts YouTube Live Chat height.

## Development

### Setup

```sh
$ pnpm install
```

### Build

For Chrome:

```sh
$ pnpm run zip
```

For Firefox:

```sh
$ pnpm run zip:firefox
```
